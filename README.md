# The World in One Day — Thursday 26 November 2026

One image summing up the world's news of Thursday 26 November 2026.

40 stories, all dated Thursday 26 November 2026: 3 top stories with dek lines, 10 featured stories with toon illustration panels, 27 more in the ALSO TODAY list, a DATE CHECK box listing the big 25 November stories left out on purpose, with every story carrying its source on the image.

The image was rendered with the Remotion + Three.js toon engine (real 3D toon scene stills for the 13 illustration panels, HTML Inter text for the page). The entry program is pure Python standard library: it copies the rendered image to the output path, no network, byte-identical on every run.

Run `python3 main.py` to write `entry.png` (1024×1024).

Notes:
- Every story was verified against a reputable source (Reuters, AP, BBC, UEFA, and others) as happening or first reported on 26 November 2026. Stories from 25 November (Houthi Ras Tanura claim, Dow comeback, Hera Dimorphos reveal, Shenzhou-24 launch, birthright-citizenship ruling, Netanyahu Case 4000) were left out on purpose.
- Built early on 26 November, so the set leans on Asia–Pacific morning news, overnight items first reported on 26 November, and events scheduled for later that day (Thanksgiving, Europa League, central-bank decisions). The Bank of Korea decision, the Yoon perjury ruling, the Progress 97 docking and the Bank of England / ECB / GfK releases are phrased as due today — their outcomes were not yet published when this image was made.
