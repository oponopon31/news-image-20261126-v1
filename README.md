A program that draws one editorial front page summarising the verified world
news of Thursday 26 November 2026: three illustrated lead stories, a stats
row of full-day outcomes, ten illustrated features, an "Also on Thursday"
regional list (40 stories in all), a story-locator map, a "Day in UTC"
timeline, and a Date Check. Runs offline with no network access.

Run it with:

```
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 -P -s main.py
```

It writes `out/entry.png` (1024x1024, under 1 MiB).
